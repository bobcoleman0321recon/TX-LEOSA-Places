# Sources

Status key: **Verified** = read at the source, with date. **Partly verified** = read, with a stated gap. **Unverified** = secondary source only; check before use.

Federal authorities are logged once, in `../../STATE_WORKFLOW.md` Layer 1 and `../../NJ-LEOSA-Places/docs/sources.md`.

All dates are 2026 unless noted. Texas statutes were read on the Legislature's official site, statutes.capitol.texas.gov, in the in-app browser (the site is a JavaScript app; WebFetch sees only its menu). The site shows each section's amendment history, not a single revision date; the last amendment listed is given below.
