# TX — Layer 5: sensitive places crosswalk (draft)

As of Nov 7, 2026. **Draft statuses for discussion, not final.** Groups are defined in `tx-definitions.md`. R = Restricted (cited); C = Restricted for most carriers — check your status (cited); N = No known restriction mapped — not a clearance. Mapped categories are never N.

Penal Code § 46.03 "premises" means a building or part of one; parking areas, driveways and walkways are not premises (§ 46.03(c)(4)).
